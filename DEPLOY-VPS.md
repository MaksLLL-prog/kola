# Выкладка Kolo на свой домен (reg.ru)

Домен на reg.ru — это только адрес. Чтобы сайт открывался, нужен **сервер (VPS)**, на который этот адрес будет указывать. Обычный виртуальный хостинг не подойдёт: нужны Docker и Node.js 22.

## Что понадобится

- VPS с Ubuntu 22.04/24.04 или Debian 12, от 1 ГБ памяти (подойдёт у любого провайдера, в том числе у самого reg.ru). Нужен публичный IP и доступ по SSH под root.
- Домен на reg.ru. Если домен кириллический (`.рф`), используйте его латинскую запись: `xn--...` (показана в панели reg.ru).

## Шаг 1. Направить домен на сервер

1. Личный кабинет reg.ru → **Домены** → ваш домен → **DNS-серверы и управление зоной**.
2. Убедитесь, что используются DNS-серверы reg.ru (`ns1.reg.ru`, `ns2.reg.ru`). Если стоят чужие, записи нужно править там.
3. Откройте управление зоной. **Удалите** старые записи `A` и `AAAA` для `@` и `www` (их часто ставит парковка домена). Добавьте:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` (сам домен) | IP вашего сервера |
| A | `www` | IP вашего сервера |

Названия пунктов в панели могут немного отличаться. Обновление идёт от нескольких минут до пары часов. Проверка: `nslookup ваш-домен` должен показать IP сервера.

## Шаг 2. Загрузить проект и запустить

С вашего компьютера (замените IP и имя файла):

```bash
scp kolo-updated.zip root@IP_СЕРВЕРА:/root/
ssh root@IP_СЕРВЕРА
```

Уже на сервере:

```bash
apt-get update && apt-get install -y unzip
unzip kolo-updated.zip && cd kolo
bash deploy/setup-server.sh ваш-домен.ru
```

Скрипт сам поставит Docker, откроет порты 80 и 443, создаст `.env` (пароль базы и секрет токенов генерируются автоматически) и запустит сайт. Через минуту откройте `https://ваш-домен.ru`: Caddy сам получит бесплатный сертификат Let's Encrypt.

Файл `.env` хранит секреты. Не публикуйте его и не теряйте: без `JWT_SECRET` все войдут заново, а пароль базы нужен, пока база жива.

## Обновление сайта

Загрузите новые файлы проекта поверх старых (не затирайте `.env`) и выполните в папке проекта:

```bash
docker compose up -d --build
```

## Бэкапы

```bash
bash deploy/backup.sh          # база и картинки в папку backups/, хранятся последние 14
crontab -e                     # и раз в сутки автоматически:
0 4 * * * /root/kolo/deploy/backup.sh
```

Копии лежат на том же сервере, поэтому периодически скачивайте их к себе (`scp -r root@IP:/root/kolo/backups .`).

## Если не работает

| Симптом | Причина |
|---|---|
| Сайт не открывается, а `nslookup` показывает чужой IP | DNS ещё не обновился или остались старые `A`/`AAAA` записи |
| Браузер ругается на сертификат | DNS не успел обновиться или закрыты порты 80/443 (проверьте и файрвол в панели провайдера VPS). Смотрите `docker compose logs caddy` |
| Ошибка 502 | приложение не стартовало: `docker compose logs app` |
| Вход слетает после перезапуска | потерян или пуст `JWT_SECRET` в `.env` |

Локальная база из `data/kolo.db` на сервер автоматически не переезжает: в продакшене используется Postgres, и сайт стартует пустым.
